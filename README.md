# SafeGrd Homebrew tap

```sh
brew install safegrd/tap/safegrd
```

Installs the [SafeGrd CLI](https://github.com/safegrd/cli) from the same release
archives as `curl -fsSL https://safegrd.dev/install.sh | sh`. Then connect the
machine:

```sh
safegrd login     # prints a URL; open it in a browser on any device
safegrd enroll
```

`Formula/safegrd.rb` is generated by the CLI's release workflow on every tag.
Do not edit it by hand; the next release overwrites it.
